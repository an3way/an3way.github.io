EXHIBIT 01 · PYTHON, 2026

Breach Checker

A privacy-first command-line tool that checks whether an email or password has surfaced in a known public breach, without ever sending the password itself over the network.

  • Password lookups use k-anonymity: only a 5-character hash prefix leaves the device, matching the approach used by HaveIBeenPwned's range API.
  • Built on the XposedOrNot API with Keccak-512 hashing as a free alternative to paid breach-check endpoints.
  • Nothing entered is logged, cached, or stored locally.

03 / CURATOR'S NOTE

Curious about
what sits underneath.

I combine visual design, technical curiosity, security awareness, and AI experimentation to build digital experiences that are clear, useful, and memorable.

01

Learn by taking things apart

Most of what I know came from breaking something on purpose: a driver, a build script, a firmware handshake, then reading the failure closely.

02

Privacy is a design constraint, not a feature

Tools should default to telling you the least about yourself that they can get away with, and still be useful.

03

Ship the plain version first

A working command-line tool beats an unfinished polished one. Interfaces come after the thing is true.
